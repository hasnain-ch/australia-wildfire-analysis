# 🇦🇺 Australian Wildfire Data Analysis & Geospatial Visualization

##  Project Overview
An in-depth data analysis project analyzing historical wildfire activities across 7 Australian regions using NASA FIRMS satellite dataset. 

## 🛠️ Tech Stack & Libraries
* **Language:** Python
* **Data Processing:** Pandas, NumPy
* **Data Visualization:** Matplotlib, Seaborn, Plotly
* **Dashboard App:** Dash
* **Geospatial Mapping:** Folium

##  Key Insights & Analysis Tasks
1. **Time-Series Analysis:** Trends of average estimated fire area over time.
2. **Brightness & Radiative Power:** Daily mean distribution of estimated fire brightness (Kelvin).
3. **Regional Heatmaps:** Interactive spatial mapping using Folium to identify high-risk fire zones.
4. **Interactive Dashboard:** Dynamic Dash web application (`app.py`) for custom regional and annual filter analysis.
